## TimeLine ##

### Phase 1: Part 1 — Project Initiation & Building the Foundation (Weeks 1–5) ###

Focus: Proposal approval, content research, asset sourcing, HTML structure, and GitHub repository setup. 
- 	Week 1–2 (Project Planning & Proposals): - 
    Draft and submit two distinct Website Project Proposals (e.g., UVIE) to the lecturer for approval.
	Define organizational goals, target audience, technical requirements, and budget.
	Create visual low-fidelity wireframes and a website sitemap.
- Week 3 (Content Research & Asset Sourcing): -
	Research and legally source text, high-resolution product photos, and vector graphics.
	Establish a structured local project directory with subfolders for images and document assets.
-	Week 4–5 (HTML Coding & Repository Initialization): 
	Set up the private GitHub repository and clone it locally.
	Code semantic HTML5 boilerplate structures for all 6 required pages (index.html, about.html, contact.html, products.html, wishlist.html, and calculations.html).
	Build a functional navigation menu linking all pages across the site.
	Draft the initial README.md and complete the Part 1 Submission.

Phase 2: Part 2 — Designing Visuals & Responsive Layouts (Weeks 5–8)
	Focus: CSS styling, implementing the "Space Odyssey" color theme, responsive media queries, and feedback integration.
- Week 5–6 (Part 1 Feedback & Baseline Styling): 
	Review Part 1 lecturer feedback, make required HTML fixes, and record every change in the GitHub repository README.md Changelog section.
	Create an external CSS stylesheet (style.css) linked across all HTML pages.
	Apply global typography, layout alignment, and the dark "Space Odyssey" visual theme.
	Week 7–8 (Responsive Design & Mobile Optimization): 
	Implement mobile-first CSS media queries and flexbox/grid breakpoints for desktop, tablet, and mobile viewports.
	Ensure navigation menus and product showcase images resize fluidly without horizontal scrolling. 
	Regularly push descriptive commits to GitHub and complete the Part 2 Submission. 

Phase 3: Part 3 — Functionality, SEO & Web Deployment (Weeks 9–12)
	Focus: JavaScript interactivity, form validation, Search Engine Optimization (SEO), live deployment, and final presentation.
-	Week 9 (Part 2 Feedback & JavaScript Enhancements): 
	Implement feedback from Part 2 and update the project changelog.
	Write JavaScript functions to handle dynamic calculations on the custom PC builder page and wishlist interactions.
	Week 10 (Interactive Forms & Validation): 
	Build client-side JavaScript validation for contact and enquiry forms to check for empty fields and valid email formats before submission.
-	Week 11 (On-Page & Technical SEO Optimization): 
	Optimize title tags, meta descriptions, semantic header hierarchy 
-	Week 12 (Testing, Live Deployment & Final Submission): 
	Perform cross-browser testing across Google Chrome and secondary browsers.
	Deploy the live website using a free hosting platform (e.g., Netlify or GitHub Pages)
	Finalize the README.md, update all references, verify GitHub commit logs, and hand in the final Summative POE
